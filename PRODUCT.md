# Product

## Register

product

## Platform

web

## Users

Field installers, site technicians, and project supervisors working on active construction and installation sites ("obras"). Primary context is mobile smartphones and tablets on-site in direct sunlight or low-connectivity environments. The primary job to be done is checking daily task assignments, recording installation progress, capturing photographic evidence, and syncing updates effortlessly.

## Product Purpose

Torven Instaladores is an offline-first field management web application built to streamline site installation workflows. It empowers field teams to operate seamlessly without internet connectivity, queuing actions locally and syncing automatically when online. Success means zero lost data, zero site delays, and instant progress reporting.

## Positioning

Zero-friction field management that works offline as reliably as online, giving site teams immediate clarity and confidence on every job.

## Brand Personality

Rugged, dependable, precise. 3-word personality: Industrial, Crisp, Unstoppable. Visual tone is focused and functional, instilling trust and speed in challenging physical environments.

## Anti-references

Low-contrast gray text on dark backgrounds, bloated desktop tables forced onto mobile screens, decorative glassmorphism or distracting hero gradients, tiny tap targets, and uninformative loading spinners that stall field operations.

## Design Principles

1. **Field-First Touch Usability**: Design for single-thumb navigation, generous touch targets (≥48px), and high contrast for outdoor sunlight readability.
2. **Unflinching Offline Transparency**: UI states must clearly communicate connection status, pending offline sync queues, and optimistic updates without blocking user flow.
3. **Task-Focused Visual Weight**: Emphasize actionable elements (capture photo, complete milestone, submit report) using Torven High-Visibility Solar Yellow `#ffc61e` while keeping secondary chrome minimal.
4. **Industrial Clarity**: Pair crisp typography with a deep black palette (`#000000` / `#09090b`), avoiding decorative fluff or complex nested card hierarchies.

## Accessibility & Inclusion

WCAG 2.1 AA compliant text and UI contrast ratios (≥4.5:1 body text contrast). Supports `prefers-reduced-motion` for instant field responses, large touch target bounds, and high-visibility status indicators.
